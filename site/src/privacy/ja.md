# プライバシーポリシー - Tabinet

最終更新日: 2026年11月2日

## 概要

Tabinet は、ブラウザのタブを並べ替えて整理し、ウィンドウとタブのまとまりをセッションとして保存、復元、検索、インポート、エクスポートできる Chrome 拡張機能です。求めに応じて、YouTube タブの動画を一時停止することもできます。私たちはプライバシーを大切に考えています。任意のクラウド同期にログインしない限り（下の「クラウド同期」を参照）、この拡張機能が行うことはすべて、ブラウザの中、つまりお使いの端末の中で完結します。

## データの収集

クラウド同期にログインしない限り、Tabinet は個人データを**収集も送信もしません**。ネットワーク通信を行わず、すべての処理はブラウザ内でローカルに行われます。クラウド同期は任意の機能で、ログインするまでオフです。何を送信し、どう保護するかは下の「クラウド同期」で説明します。いずれの場合も、閲覧したページの内容を読み取らず、アクセス解析、トラッキング、テレメトリーも使いません。ウェブページの中で実行するのは YouTube 動画の一時停止だけで、それも許可された後に限ります（下の「YouTube 動画の一時停止」を参照）。

### 何を、どこに保存するか

セッションを保存したとき、および自動スナップショットが有効な間（下記参照）、拡張機能は開いているウィンドウについて次の情報を、この端末の Chrome のローカル拡張機能ストレージ（`chrome.storage.local`）に保存します。

- 各タブ: URL、ページのタイトル、固定タブかどうか、アクティブなタブだったかどうか
- 各タブグループ: 名前、色、折りたたまれていたかどうか
- 各ウィンドウ: 状態（通常、最小化、最大化、全画面）、大きさと位置、フォーカスのあるウィンドウだったかどうか
- 各セッション: 付けた名前（または自動で付いた既定の名前）、保存日時と最終変更日時、同じスナップショットを二重に保存しないために使うタブ配置の短いフィンガープリント
- セッションの設定: 自動スナップショットのオン/オフ、間隔、保持する件数、大きなセッションの復元方法

シークレット ウィンドウ、空のウィンドウ、拡張機能自身のページは記録しません。Tabinet のページに表示されるサイトのアイコンは Chrome 自身のファビコン キャッシュから取得しており、拡張機能が保存することはありません。

クラウド同期を使わない限り、これらのデータが端末の外に出ることはありません。Chrome の同期で同期されることも、サーバーにアップロードされることもなく、ウェブページからアクセスすることもできません。セッションのデータが拡張機能の外に出るのは、ユーザーが選んだときだけです。エクスポートは、ユーザーが明示的に操作したときに限り、ファイルを作成するかテキストをクリップボードにコピーします。また、クラウド同期にログインした場合は、保存したセッション（自動スナップショットは除く）が、下で説明するとおりエンドツーエンドで暗号化されて同期サーバーに送信されます。

並べ替えの設定（グループ化の方法と重複タブの扱い）と、設定で選んだ拡張機能の言語（選んだ場合）は、拡張機能のインストール時または更新時に記録したバージョン番号とともに Chrome の同期ストレージに保存されます。Chrome の同期を有効にしている場合、これらの設定、そしてそれだけが、同じ Chrome アカウントでログインしている端末間で同期されることがあります。セッションのデータとセッションの設定が Chrome の同期ストレージに保存されることはありません。

### 自動スナップショット

自動スナップショットは**初期状態でオン**です。5分ごと（または1分から24時間の範囲で選んだ間隔ごと）、およびアイコンをクリックして並べ替えるたびに、拡張機能は上記のとおり開いているウィンドウの配置を記録します。ただし、前回のスナップショットから変化があった場合に限ります。スナップショットは保存したセッションと同じローカル ストレージに保存され、同じルールに従います。

スナップショットをオフにするには、Tabinet を開き（アイコンを右クリック → オプション）、設定で自動スナップショットをオフにしてください。オフの間はタイマーが存在しません。それでも拡張機能は、Chrome の起動時、インストールや更新の時、設定を変更した時に短時間だけ動作し、保存済みのデータを整理します。そのいずれもネットワークは使いません。

### YouTube 動画の一時停止

アイコンの右クリックメニューとショートカットキーにある「YouTube の動画をすべて一時停止」は、すべてのウィンドウで開いている YouTube タブの、再生中の動画と音声をすべて一時停止します。再生位置はそのままで、ミュート、タブを閉じる、再読み込みは一切行いません。

そのために、拡張機能には youtube.com へのアクセス（`https://*.youtube.com/*`、www、m、music を含む）が必要です。インストール時には要求しません。設定で「アクセスを許可」をクリックしたときに Chrome が確認し（その前にメニュー項目を選ぶと設定が開きます）、設定または chrome://extensions でいつでもアクセスを解除できます。アクセスが許可されると、求められるたびに、拡張機能に含まれている小さな関数を 1 つ、各 YouTube タブで実行します。この関数は一時停止を押し、いくつ停止したかを数えるだけです。ページの内容や視聴履歴など YouTube のものは何も読み取らず、YouTube に関する情報を保存したり送信したりすることもありません。アクセスがなければ、どのウェブページでも何も実行しません。

### クラウド同期（任意）

クラウド同期は、Tabinet を使っている複数のパソコンの間で、保存したセッションと設定を同じ状態に保ちます。**ログインするまではオフです**。設定の「アカウント」で「Google でログイン」をクリックすると有効になります。ログインしない限り、このセクションの内容は当てはまらず、拡張機能はネットワーク通信を行いません。

**ログイン。** Chrome があなたの許可を求めたうえで、Chrome にログインしている Google アカウントの Google アクセス トークンを拡張機能に渡します。スコープは `openid` と `email` だけで、メールアドレスと Google の固定のアカウント ID 以外、Google アカウントの情報は受け取りません。拡張機能はこのトークンを Tabinet の同期サーバーに一度だけ送り、サーバーは Google に確認したあとトークンを破棄します。拡張機能も直後に Chrome のキャッシュからトークンを削除します。その後、サーバーは 90 日間有効な独自のセッション トークンを発行し、拡張機能はそれをローカル拡張機能ストレージに保存します。

**何を送信し、どう保護するか。** データが端末から出る前に、同期パスフレーズを作成します。このパスフレーズから端末内で鍵を導出し（PBKDF2、SHA-256、60万回の反復、ランダムなソルト）、同期するものはすべてこの鍵で AES-GCM（256 ビット）により暗号化します。パスフレーズと鍵がどこかに送信されることはありません。暗号化して送信するのは次のものです。

- 保存したセッション: タブの URL とタイトル、タブグループ、ウィンドウの配置、および保存したセッションの削除
- 設定: 並べ替えの設定、セッションの設定、選んだ言語

自動スナップショットが同期されることは**ありません**。サーバーはパスフレーズも鍵も持たないため、セッションや設定を読むことはできず、パスフレーズを忘れた場合は私たちを含め誰も復元できません（端末にあるセッションには影響しません）。

**サーバーに保存されるもの。** アカウントごとに、メールアドレス、Google アカウント ID、アカウントの作成日時、そして端末がパスフレーズを確認するために必要な鍵の設定（ソルト、反復回数、暗号化された確認用の値。いずれからもパスフレーズは分かりません）。ログインごとに、セッション トークンのハッシュ（トークンそのものは保存しません）と有効期限。同期した項目ごとに、暗号化された内容、セッションか設定か、ランダムな識別子、最終変更日時、削除済みかどうか。削除したセッションは、ほかの端末に削除を伝えるため、クラウドのデータを削除するまで暗号化された削除の印としてサーバーに残ります。

**保存場所。** 同期サーバーは Vercel 上で、データベースは Neon 上で動いており、どちらもシンガポール リージョン（アジア太平洋）にあります。両社はホスティング事業者として、サービスの運営のためにのみこのデータを処理します。リクエストを処理する際、Vercel は IP アドレスなどの一般的なリクエスト情報をログに記録することがあります。ログイン時には、アクセス トークンを確認する Google も関わります。

**保持と削除。** 同期したデータは、削除するまで保持されます。設定の「アカウント」にある「クラウドのデータを削除」は、アカウントとそのアカウントでサーバーに保存されたものすべてを、直ちに完全に削除します。端末にあるセッションは残ります。「ログアウト」はその端末での同期を止め、セッション トークンと鍵を消しますが、ほかの端末のためにサーバーのデータは残します。使われないセッション トークンは 90 日で失効します。

**利用目的。** 同期したデータは、あなた自身の端末の同期にのみ使います。販売せず、広告、アクセス解析、プロファイリングにも使わず、サービス運営のための上記のホスティング事業者以外とは共有しません。

## データの保持

- 保存したセッションは、Tabinet のページで削除するまで保持されます。
- 自動スナップショットは入れ替え方式で保持されます。保護されていないスナップショットのうち最新のものだけを残し（既定は20件。件数は Tabinet の設定で選べます）、古いものは自動的に削除します。保護したスナップショットは、削除するまで残ります。ブラウザの再起動後に作られる「前回のセッション（復旧）」のスナップショットは自動的に保護され、その1つ前のものも同様です。それより古い復旧スナップショットは入れ替えの対象に戻り、ほかと同じように順に削除されます。自分で保護したものは、そのまま手元に残ります。スナップショットは1件ずつでも、まとめてでも削除できます。
- Tabinet のページの「セッションデータをすべて削除」は、保存したセッションとスナップショットをすべて直ちに削除します。設定は残ります。
- 拡張機能をアンインストールすると、Chrome がその端末の保存データをすべて削除します。ログインしたことがある場合、同期サーバーのデータは「クラウドのデータを削除」で削除するまで残ります（もう一度ログインするとこのボタンを使えます）。

## 権限

この拡張機能には次の権限が必要です。

- **tabs**: 並べ替え、セッションの保存、Tabinet のページの開いているウィンドウ一覧のためにタブの URL とタイトルを読み取り、セッションの復元時にタブを作成します。
- **tabGroups**: 現在のウィンドウのタブグループを並べ替えて整理し、セッションの復元時にタブグループを作り直します。
- **storage**: 並べ替えの設定と言語の選択を Chrome の同期ストレージに保存し、保存したセッション、スナップショット、セッションの設定、およびクラウド同期を使う場合はそのセッション トークンと鍵を、この端末のローカル ストレージに保存します。
- **contextMenus**: 拡張機能アイコンの右クリックメニューに「集合！」、「すべてのウィンドウをセッションとして保存」、「YouTube の動画をすべて一時停止」を追加します。ウェブページにメニュー項目は追加しません。
- **unlimitedStorage**: 大きなセッションが Chrome のローカル ストレージの既定の上限を超えられるようにします。データの保存場所は変わらず、どこにも何も送信しません。
- **favicon**: Tabinet のページのタブの横に、Chrome のローカルのファビコン キャッシュからサイトのアイコンを表示します。ネットワークからアイコンを取得することはなく、拡張機能がアイコンのデータを保存することもありません。
- **alarms**: 選んだ間隔で自動スナップショットを取るためのタイマーとして使います。クラウド同期にログインしている間は、15分ごとと変更の直後に同期するためにも使います。自動スナップショットをオフにし、ログインしていなければ、タイマーは存在しません。
- **identity**: 「Google でログイン」をクリックしたときに、クラウド同期のためだけに使います。「クラウド同期」で説明したとおり、`openid` と `email` スコープの Google アクセス トークンを Chrome に求めます。ログインしなければ使いません。
- **scripting**: 「YouTube 動画の一時停止」で説明したとおり、求められたときに YouTube の動画を一時停止するためだけに使います。下で許可したサイトでのみ動作します。
- **youtube.com へのアクセス**（任意、`https://*.youtube.com/*`）: 設定で「アクセスを許可」をクリックしたときにのみ要求し、設定から解除できます。動画の一時停止にのみ使い、YouTube のページからは何も読み取りません。

この拡張機能はインストール時にホスト権限を要求せず、コンテンツ スクリプトも宣言しません。youtube.com へのアクセスは任意で、許可するかどうかはあなたが決めます。Chrome 123 以降が必要です。

## データの利用

- タブの URL とタイトルは並べ替えの際に読み取られますが、並べ替えのために保存されることは**ありません**。
- セッションを保存したとき、または自動スナップショットが有効な間、上記のデータは端末のローカル拡張機能ストレージに保存されます。送信されるのはクラウド同期にログインした場合だけで、それも保存したセッションと設定のみ、エンドツーエンドで暗号化されます。自動スナップショットは送信されません。
- 並べ替えの設定は Chrome に組み込まれたストレージ API で保存され、クラウド同期を使う場合は暗号化されて同期サーバーにも保存されます。第三者と共有されることはありません。
- タブの並べ替え、求められたときの YouTube 動画の一時停止、セッションの保存、復元、検索、インポート、エクスポート、およびログインした場合の同期以外の目的で、データが販売、共有、利用されることは一切ありません。

## 第三者のサービス

Tabinet は、第三者のアクセス解析、トラッキング、データ収集サービスを**使用しません**。クラウド同期は、ログインした場合にのみ、Google のログインとホスティング事業者の Vercel、Neon を使います（「クラウド同期」を参照）。
