# プライバシーポリシー - Tabinet

最終更新日: 2026年11月26日

## 概要

Tabinet は、ブラウザのタブを並べ替えて整理し、ウィンドウとタブのまとまりをセッションとして保存、復元、検索、インポート、エクスポートできる Chrome 拡張機能です。求めに応じて、YouTube タブの動画を一時停止することもでき、Chrome のサイドパネルで YouTube 動画に時刻付きのメモを残すことも、専用のページで自由メモを書くこともできます。私たちはプライバシーを大切に考えています。任意のクラウド同期にログインしない限り（下の「クラウド同期」を参照）、この拡張機能が行うことはすべて、ブラウザの中、つまりお使いの端末の中で完結します。

## データの収集

クラウド同期にログインしない限り、Tabinet は個人データを**収集も送信もしません**。ネットワーク通信を行わず、すべての処理はブラウザ内でローカルに行われます。クラウド同期は任意の機能で、ログインするまでオフです。何を送信し、どう保護するかは下の「クラウド同期」で説明します。いずれの場合も、アクセス解析、トラッキング、テレメトリーは使わず、下で説明する YouTube の場合を除いて、閲覧したページの内容を読み取りません。ウェブページの中で何かを実行するのは YouTube だけで、それも許可された後に限ります。動画を一時停止し、YouTube メモのために、メモを取っている動画の時刻とタイトルを読み取り、求められたときにはスクリーンショットを撮ります（下の「YouTube 動画の一時停止」と「YouTube メモ」を参照）。

### 何を、どこに保存するか

セッションを保存したとき、および自動スナップショットが有効な間（下記参照）、拡張機能は開いているウィンドウについて次の情報を、この端末の Chrome のローカル拡張機能ストレージ（`chrome.storage.local`）に保存します。

- 各タブ: URL、ページのタイトル、固定タブかどうか、アクティブなタブだったかどうか
- 各タブグループ: 名前、色、折りたたまれていたかどうか
- 各ウィンドウ: 状態（通常、最小化、最大化、全画面）、大きさと位置、フォーカスのあるウィンドウだったかどうか
- 各セッション: 付けた名前（または自動で付いた既定の名前）、保存日時と最終変更日時、同じスナップショットを二重に保存しないために使うタブ配置の短いフィンガープリント
- 各自由メモ: 書いた本文、書いた日時と最終変更日時、および同期の競合で残したコピーの場合はどのメモから作られたか
- セッションの設定: 自動スナップショットのオン/オフ、間隔、保持する件数、大きなセッションの復元方法

シークレット ウィンドウ、空のウィンドウ、拡張機能自身のページは記録しません。Tabinet のページに表示されるサイトのアイコンは Chrome 自身のファビコン キャッシュから取得しており、拡張機能が保存することはありません。

クラウド同期を使わない限り、これらのデータや自由メモが端末の外に出ることはありません。Chrome の同期で同期されることも、サーバーにアップロードされることもなく、ウェブページからアクセスすることもできません。セッションのデータが拡張機能の外に出るのは、ユーザーが選んだときだけです。エクスポートは、ユーザーが明示的に操作したときに限り、ファイルを作成するかテキストをクリップボードにコピーします。また、クラウド同期にログインした場合は、保存したセッションと自由メモ（自動スナップショットは除く）が、下で説明するとおりエンドツーエンドで暗号化されて同期サーバーに送信されます。

並べ替えの設定（グループ化の方法と重複タブの扱い）と、設定で選んだ拡張機能の言語（選んだ場合）は、拡張機能のインストール時または更新時に記録したバージョン番号とともに Chrome の同期ストレージに保存されます。Chrome の同期を有効にしている場合、これらの設定、そしてそれだけが、同じ Chrome アカウントでログインしている端末間で同期されることがあります。セッションのデータとセッションの設定が Chrome の同期ストレージに保存されることはありません。

### 自動スナップショット

自動スナップショットは**初期状態でオン**です。5分ごと（または1分から24時間の範囲で選んだ間隔ごと）、およびアイコンをクリックして並べ替えるたびに、拡張機能は上記のとおり開いているウィンドウの配置を記録します。ただし、前回のスナップショットから変化があった場合に限ります。スナップショットは保存したセッションと同じローカル ストレージに保存され、同じルールに従います。

スナップショットをオフにするには、Tabinet を開き（アイコンを右クリック → オプション）、設定で自動スナップショットをオフにしてください。オフの間はスナップショットのタイマーが存在しません（クラウド同期にログインしている場合、同期のタイマーは動作します）。それでも拡張機能は、Chrome の起動時、インストールや更新の時、設定を変更した時に短時間だけ動作し、保存済みのデータを整理します。クラウド同期を使わなければ、そのいずれもネットワークは使いません。クラウド同期にログインしている場合は、変更した設定を数秒以内に送信し（同期に失敗している間は次の再試行時、最長15分後）、未送信の変更は Chrome の起動後に送信します。

### YouTube 動画の一時停止

アイコンの右クリックメニューとショートカットキーにある「YouTube の動画をすべて一時停止」は、すべてのウィンドウで開いている YouTube タブの、再生中の動画と音声をすべて一時停止します。再生位置はそのままで、ミュート、タブを閉じる、再読み込みは一切行いません。

そのために、拡張機能には youtube.com へのアクセス（`https://*.youtube.com/*`、www、m、music を含む）が必要です。インストール時には要求しません。設定で「YouTube へのアクセス」をオンにしたときに Chrome が確認し（その前にメニュー項目を選ぶと設定が開きます）、設定または chrome://extensions でいつでもアクセスを解除できます。アクセスが許可されると、求められるたびに、拡張機能に含まれている小さな関数を 1 つ、各 YouTube タブで実行します。この関数は一時停止を押し、いくつ停止したかを数えるだけです。ページの内容や視聴履歴など YouTube のものは何も読み取らず、YouTube に関する情報を保存したり送信したりすることもありません。アクセスがなければ、どのウェブページでも何も実行しません。

### YouTube メモ

「YouTube メモ」（アイコンの右クリックメニュー、自分で割り当てられるショートカットキー、Tabinet のページのボタン）は、ページの横に Chrome のサイドパネルを開きます。そのウィンドウのアクティブなタブに YouTube の動画が表示されている間、動画の特定の時刻にメモを書くことができ、メモの時刻をクリックすると動画がその位置へ移動します。

メモを書いた動画ごとに、拡張機能はこの端末のローカル拡張機能ストレージ（`chrome.storage.local`）に次を保存します。動画の ID とアドレス（`https://www.youtube.com/watch?v=<id>`）、タイトル、各メモの内容とそのメモが属する動画の時刻、メモのために撮ったスクリーンショット（動画の画面の画像で、幅は最大 1280 ピクセル）、各メモを書いた日時と最後に変更した日時です。メモを削除すると、そのスクリーンショットも削除されます。クラウド同期を使わない限り、メモが端末の外に出ることはありません。クラウド同期にログインした場合は、メモは 1 件ずつ、スクリーンショットと一緒に、それぞれ独立したエンドツーエンド暗号化の項目として同期されます。動画の ID とタイトルは暗号化された内容の中にしかありません（下の「クラウド同期」を参照）。

動作には一時停止と同じ youtube.com へのアクセス（上記を参照）が必要で、同じ「YouTube へのアクセス」スイッチで求めます。許可されると、パネルが動画に対して開いている間、拡張機能に含まれる小さな関数が、パネルが表示されている間はおよそ1秒ごとに、その動画の現在の時刻、長さ、再生中かどうか、ページのタイトルを読み取ります。求められたときには動画をメモの時刻へ移動し、「書いている間は動画を一時停止」をオンにしていれば、メモを書いている間は一時停止し、書き終えたら再生を再開します。「スクリーンショット」を押すと、その瞬間に動画に映っている画面を画像にしてパネルに渡し、パネルはそれを新しいメモと一緒に保存します。ページからそれ以外のものは読み取らず、読み取った内容は保存したメモの一部としてのみ保存されます。

### クラウド同期（任意）

クラウド同期は、Tabinet を使っている複数のコンピュータで、保存したセッション、自由メモ、YouTube メモと設定をそろえます。**ログインするまではオフです**。設定のアカウントで「Google でログイン」をクリックすると始まります。ログインしなければ、この節の内容は当てはまらず、拡張機能はネットワーク通信を一切行いません。バージョン 10 より前のバージョンは、もう同期できません。それらのバージョンで同期したデータは、バージョン 10 のサーバーが動き始めたときに消去されました。端末上のデータは消えていません。

**ログイン。** Chrome は拡張機能に、`openid` と `email` スコープに限った Google アクセス トークンを渡します。中身はメールアドレスと Google の固定のアカウント ID だけです。拡張機能はこれを Tabinet の同期サーバーに送り、サーバーは Google に確認したうえで破棄し、拡張機能は Chrome のキャッシュから削除します。同期パスフレーズを作成、入力、変更するときと、クラウドのデータを削除するときにも、同じ確認をもう一度行います。サーバーはブラウザに 90 日間有効なセッション トークンを渡します。この端末が最後に別のアカウントと同期していた場合は、新しいアカウントにデータをアップロードする前に確認します。

**鍵。** 最初の端末がランダムなデータ鍵を作り、同期するものはすべてこの鍵で暗号化します（AES-GCM、256 ビット）。データ鍵そのものは、端末上でパスフレーズから導いた鍵で暗号化されます（SHA-256 による PBKDF2、60 万回、ランダムなソルト）。サーバーが受け取るのはこの暗号化された鍵だけで、サーバー自身の鍵でもう一度封をし、Google がアカウントを確認した後にだけ渡します。パスフレーズとデータ鍵が送信されることはありません。バージョン 10 が保存する内容には、サーバー自身の鍵なしにパスフレーズを試せるものは含まれません。データベース事業者の復旧用履歴にはバージョン 9 のパスフレーズの記録がしばらく残ることがあるため、これまで同期に使ったことのないパスフレーズを選んでください。サーバーを支配し、その鍵とデータベースを持つ人や、あなたとして Google にログインできる人は、パスフレーズを推測しようとするかもしれません。Google のパスワードとは別の、強いパスフレーズを選んでください。

データ鍵は、ロックを解除した各端末のローカル拡張機能ストレージに残ります。ログインの有効期限が切れた後も、その端末でログアウトするか、クラウドのデータを削除するか、別のアカウントの鍵に置き換えるまで残ります。そのブラウザのプロファイルやそのバックアップにアクセスできる人は、この鍵を読めます。ロックを解除した端末は、Google の確認を経て、古いパスフレーズなしで新しいパスフレーズを設定できます。パスフレーズを変更してもデータ鍵は変わらないため、すでにその鍵を手に入れた人のアクセスは取り消せません。クラウドのデータを削除してやり直せば取り消せます。

**送信されるもの（暗号化済み）。**

- 保存したセッション: タブの URL とタイトル、タブグループ、ウィンドウの配置、およびセッションの削除
- 自由メモとその削除
- YouTube メモ（メモ 1 件につき 1 項目）: 動画の ID とタイトル、メモの本文と時刻、およびその削除
- メモのために撮ったスクリーンショットとその削除
- 設定: 並べ替えの設定、セッションの設定、言語

自動スナップショットが同期されることは**ありません**。1 つのアカウントに保存できるのは、削除の印を含めて最大 50 MB の暗号化データと、最大 100 枚のスクリーンショットです。収まらないものは端末に残り、拡張機能がそのことを知らせます。削除はいつでもできます。

**サーバーが保存し、見られるもの。** アカウントについて: メールアドレス、Google アカウント ID、作成日時、封をした鍵、その鍵の識別子と変更番号、データ鍵を持つ人だけが鍵を置き換えられるようにするハッシュ、使用中の保存容量。ログインごとに: セッション トークンのハッシュと有効期限。項目ごとに: 暗号化された内容、それがセッション、設定、スクリーンショット、ドキュメントのどれか、ランダムまたは意味の読み取れない識別子、サイズ、変更日時、削除されたかどうか。自由メモと YouTube メモはサイズ以外では見分けがつきません。動画の ID が暗号化された内容の外に出ることはありません。データ鍵がなければ、誰も項目を読むことも偽造することもできません。サーバーを支配する人や、セッション トークンを持つ人は、項目を渡さない、上書きする、削除する、古い状態に戻す、といったことができます。

**場所。** 同期サーバーは Vercel、データベースは Neon で動いており、どちらもシンガポール リージョンにあります。両社はホスティング事業者として働きます。Vercel は、IP アドレスなど一般的なリクエスト情報をログに記録することがあります。アクセス トークンは Google が確認します。

**保持と削除。** 同期したデータと削除の印は、削除するまで保持されます。設定のアカウントにある「クラウドのデータを削除」は、Google の確認を経て、アカウントとそこに保存されたすべてのものを稼働中のデータベースから削除します。データベース事業者の復旧用履歴には、その後もしばらく残ることがあります。端末上のデータは残ります。「ログアウト」は、その端末のセッション トークンとデータ鍵を破棄し、クラウドのコピーはそのまま残します。

**利用。** 同期したデータは、あなた自身の端末を同期するためだけに使われます。販売されることも、広告、分析、プロファイリングに使われることも、上記の事業者以外と共有されることもありません。

## データの保持

- 保存したセッションは、Tabinet のページで削除するまで保持されます。
- 自動スナップショットは入れ替え方式で保持されます。保護されていないスナップショットのうち最新のものだけを残し（既定は20件。件数は Tabinet の設定で選べます）、古いものは自動的に削除します。保護したスナップショットは、削除するまで残ります。ブラウザの再起動後に作られる「前回のセッション（復旧）」のスナップショットは自動的に保護され、その1つ前のものも同様です。それより古い復旧スナップショットは入れ替えの対象に戻り、ほかと同じように順に削除されます。自分で保護したものは、そのまま手元に残ります。スナップショットは1件ずつでも、まとめてでも削除できます。
- 自由メモは、Tabinet のページで削除するまで保持されます。削除した後も数秒間は元に戻せます。
- Tabinet のページの「セッションデータをすべて削除」は、保存したセッションとスナップショットをすべて直ちに削除します。設定、YouTube メモ、自由メモは残ります。
- YouTube メモは、メモパネルか Tabinet のページで削除するまで保持されます。動画の最後のメモを削除すると、その動画について保存したものはすべて削除されます。
- 拡張機能をアンインストールすると、Chrome がその端末の保存データをすべて削除します。ログインしたことがある場合、同期サーバーのデータは「クラウドのデータを削除」で削除するまで残ります（もう一度ログインするとこのボタンを使えます）。

## 権限

この拡張機能には次の権限が必要です。

- **tabs**: 並べ替え、セッションの保存、Tabinet のページの開いているウィンドウ一覧のためにタブの URL とタイトルを読み取り、セッションの復元時にタブを作成します。
- **tabGroups**: 現在のウィンドウのタブグループを並べ替えて整理し、セッションの復元時にタブグループを作り直します。
- **storage**: 並べ替えの設定と言語の選択を Chrome の同期ストレージに保存し、保存したセッション、スナップショット、セッションの設定、YouTube メモ、自由メモ、およびクラウド同期を使う場合はそのセッション トークン、データ鍵、同期の記録を、この端末のローカル ストレージに保存します。
- **contextMenus**: 拡張機能アイコンの右クリックメニューに「集合！」、「すべてのウィンドウをセッションとして保存」、「YouTube の動画をすべて一時停止」、「YouTube メモ」を追加します。ウェブページにメニュー項目は追加しません。
- **unlimitedStorage**: 大きなセッションが Chrome のローカル ストレージの既定の上限を超えられるようにします。データの保存場所は変わらず、どこにも何も送信しません。
- **favicon**: Tabinet のページのタブの横に、Chrome のローカルのファビコン キャッシュからサイトのアイコンを表示します。ネットワークからアイコンを取得することはなく、拡張機能がアイコンのデータを保存することもありません。
- **alarms**: 選んだ間隔で自動スナップショットを取るためのタイマーとして使います。クラウド同期にログインしている間は、15分ごとの変更の確認、変更を送る前に Chrome が拡張機能を停止した場合の送信、失敗した同期の再試行にも使います。自動スナップショットをオフにし、ログインしていなければ、タイマーは存在しません。
- **identity**: 「Google でログイン」をクリックしたとき、およびパスフレーズの作成、入力、変更やクラウドのデータの削除の際にアカウントを確認するために、クラウド同期のためだけに使います。「クラウド同期」で説明したとおり、`openid` と `email` スコープの Google アクセス トークンを Chrome に求めます。ログインしなければ使いません。
- **scripting**: YouTube でのみ使います。「YouTube 動画の一時停止」で説明したとおり、求められたときに動画を一時停止し、「YouTube メモ」で説明したとおり、動画の時刻とタイトルを読み取ってメモの時刻へ移動し、求められたときにはスクリーンショットを撮ります。下で許可したサイトでのみ動作します。
- **sidePanel**: 右クリックメニュー、ショートカットキー、Tabinet のページから開いたときに、Chrome のサイドパネルに YouTube メモを表示します。アイコンをクリックしても開きません。
- **youtube.com へのアクセス**（任意、`https://*.youtube.com/*`）: 設定またはメモパネルで「YouTube へのアクセス」をオンにしたときにのみ要求し、設定から解除できます。動画の一時停止と、YouTube メモのために動画の時刻とタイトルを読み取り、位置を移動し、求められたときにスクリーンショットを撮ることにのみ使い、YouTube のページからそれ以外のものは読み取りません。

この拡張機能はインストール時にホスト権限を要求せず、コンテンツ スクリプトも宣言しません。youtube.com へのアクセスは任意で、許可するかどうかはあなたが決めます。Chrome 123 以降が必要です。

## データの利用

- タブの URL とタイトルは並べ替えの際に読み取られますが、並べ替えのために保存されることは**ありません**。
- セッションを保存したとき、または自動スナップショットが有効な間、上記のデータは端末のローカル拡張機能ストレージに保存されます。書いた自由メモもそこに保存されます。これらのデータが送信されるのはクラウド同期にログインした場合だけで、それも保存したセッション、自由メモ、YouTube メモとそのスクリーンショット、設定のみ、エンドツーエンドで暗号化されます。自動スナップショットは送信されません。
- 並べ替えの設定は Chrome に組み込まれたストレージ API で保存され、クラウド同期を使う場合は暗号化されて同期サーバーにも保存されます。第三者と共有されることはありません。
- タブの並べ替え、求められたときの YouTube 動画の一時停止、YouTube 動画へのメモと自由メモの保存、セッションの保存、復元、検索、インポート、エクスポート、およびログインした場合のセッション、自由メモ、YouTube メモの同期以外の目的で、データが販売、共有、利用されることは一切ありません。

## 第三者のサービス

Tabinet は、第三者のアクセス解析、トラッキング、データ収集サービスを**使用しません**。クラウド同期は、ログインした場合にのみ、Google のログインとホスティング事業者の Vercel、Neon を使います（「クラウド同期」を参照）。
