# 개인정보처리방침 - Tabinet

최종 수정일: 2026년 11월 12일

## 개요

Tabinet은 브라우저 탭을 정렬하고 정리하며, 여러 창과 탭을 세션으로 저장, 복원, 검색, 가져오기, 내보내기할 수 있게 해 주는 Chrome 확장 프로그램입니다. 요청하면 YouTube 탭의 동영상을 일시중지하며, Chrome 사이드 패널에서 YouTube 동영상에 시간이 표시된 메모를 남길 수도 있습니다. 저희는 개인정보를 중요하게 생각합니다. 사용자가 선택 기능인 클라우드 동기화에 로그인하지 않는 한(아래 "클라우드 동기화" 참고), 이 확장 프로그램이 하는 모든 일은 브라우저 안, 사용자의 기기에서 이루어집니다.

## 데이터 수집

클라우드 동기화에 로그인하지 않으면 Tabinet은 어떤 개인 데이터도 **수집하거나 전송하지 않습니다**. 네트워크 요청을 하지 않으며 모든 작업은 브라우저 안에서 로컬로 처리됩니다. 클라우드 동기화는 선택 기능이며 로그인하기 전까지 꺼져 있습니다. 무엇을 보내고 어떻게 보호하는지는 아래 "클라우드 동기화"에 설명합니다. 어느 경우든 분석, 추적, 원격 측정 도구를 쓰지 않으며, 아래에 설명한 YouTube의 경우를 빼고는 방문한 페이지의 내용을 읽지 않습니다. 웹페이지 안에서 무언가를 실행하는 것은 YouTube뿐이며, 그것도 사용자가 허용한 뒤에만 실행합니다. YouTube 동영상을 일시중지하고, YouTube 메모를 위해 메모하는 동영상의 시간과 제목을 읽고, 사용자가 요청하면 스크린샷을 찍습니다(아래 "YouTube 동영상 일시중지"와 "YouTube 메모" 참고).

### 무엇을, 어디에 저장하나요

세션을 저장할 때, 그리고 자동 스냅샷이 켜져 있는 동안(아래 참고), 확장 프로그램은 열린 창에 관한 다음 정보를 이 기기의 Chrome 로컬 확장 프로그램 저장소(`chrome.storage.local`)에 저장합니다.

- 각 탭: URL, 페이지 제목, 고정된 탭인지 여부, 활성 탭이었는지 여부
- 각 탭 그룹: 이름, 색상, 접혀 있었는지 여부
- 각 창: 상태(일반, 최소화, 최대화, 전체 화면), 크기와 위치, 포커스된 창이었는지 여부
- 각 세션: 사용자가 붙인 이름(또는 자동으로 만든 기본 이름), 저장한 시각과 마지막으로 바뀐 시각, 똑같은 스냅샷을 두 번 저장하지 않도록 쓰는 탭 배치의 짧은 지문
- 세션 설정: 자동 스냅샷 사용 여부, 간격, 보관 개수, 큰 세션을 복원하는 방식

시크릿 창, 빈 창, 확장 프로그램 자체의 페이지는 저장하지 않습니다. Tabinet 화면에 보이는 사이트 아이콘은 Chrome 자체의 파비콘 캐시에서 가져오며, 확장 프로그램이 저장하지 않습니다.

클라우드 동기화를 쓰지 않으면 이 데이터는 기기를 떠나지 않습니다. Chrome 동기화로 동기화되지 않고, 어떤 서버에도 업로드되지 않으며, 웹페이지에서 접근할 수 없습니다. 세션 데이터는 사용자가 선택할 때만 확장 프로그램 밖으로 나갑니다. 내보내기는 사용자가 명시적으로 실행했을 때에만 파일을 만들거나 클립보드에 텍스트를 복사하고, 클라우드 동기화에 로그인하면 저장된 세션(자동 스냅샷은 제외)이 아래 설명처럼 종단 간 암호화되어 동기화 서버로 전송됩니다.

정렬 환경설정(그룹 방식, 중복 탭 처리 방식)과 설정에서 고른 확장 프로그램 언어(고른 경우)는 확장 프로그램을 설치하거나 업데이트할 때 기록한 버전 번호와 함께 Chrome 동기화 저장소에 저장됩니다. Chrome 동기화를 켜 두었다면 이 환경설정, 그리고 그것만이 같은 Chrome 계정에 로그인한 기기 사이에서 동기화될 수 있습니다. 세션 데이터와 세션 설정은 Chrome 동기화 저장소에 절대 저장되지 않습니다.

### 자동 스냅샷

자동 스냅샷은 **기본으로 켜져 있습니다**. 5분마다(또는 1분에서 24시간 사이에서 사용자가 고른 간격마다), 그리고 아이콘을 클릭해 정렬할 때마다, 확장 프로그램은 위에서 설명한 대로 열린 창의 배치를 기록합니다. 단, 마지막 스냅샷 이후 무언가 바뀌었을 때만 기록합니다. 스냅샷은 저장된 세션과 같은 로컬 저장소에 보관되며 같은 규칙을 따릅니다.

스냅샷을 끄려면 Tabinet을 열고(아이콘을 마우스 오른쪽 버튼으로 클릭 → 옵션) 설정에서 자동 스냅샷을 끄세요. 스냅샷을 끄면 타이머가 존재하지 않습니다. 그래도 확장 프로그램은 Chrome이 시작될 때, 설치되거나 업데이트될 때, 설정을 바꿀 때 잠깐 깨어나 저장된 데이터를 정돈합니다. 이 중 어느 것도 네트워크를 쓰지 않습니다.

### YouTube 동영상 일시중지

아이콘의 마우스 오른쪽 버튼 메뉴와 단축키에 있는 "모든 YouTube 동영상 일시중지"는 모든 창에서 열려 있는 YouTube 탭의 재생 중인 동영상과 오디오를 모두 일시중지합니다. 재생 위치는 그대로이며, 음소거하거나 탭을 닫거나 새로고침하지 않습니다.

이를 위해 확장 프로그램에는 youtube.com 접근 권한(`https://*.youtube.com/*`, www, m, music 포함)이 필요합니다. 설치할 때는 요청하지 않습니다. 설정에서 "YouTube 접근 권한"을 켜면 Chrome이 묻고(그 전에 메뉴 항목을 고르면 설정이 열립니다), 설정이나 chrome://extensions에서 언제든 접근을 해제할 수 있습니다. 접근이 허용되면 사용자가 요청할 때마다 확장 프로그램에 들어 있는 작은 함수 하나를 각 YouTube 탭에서 실행합니다. 이 함수는 일시중지를 누르고 몇 개를 멈췄는지만 셉니다. 페이지 내용, 시청 기록 등 YouTube의 어떤 것도 읽지 않으며, YouTube에 관한 어떤 정보도 저장하거나 전송하지 않습니다. 접근 권한이 없으면 어떤 웹페이지에서도 아무것도 실행하지 않습니다.

### YouTube 메모

"YouTube 메모"(아이콘의 마우스 오른쪽 버튼 메뉴, 직접 지정할 수 있는 단축키, Tabinet 화면의 버튼)는 페이지 옆에 Chrome 사이드 패널을 엽니다. 그 창의 활성 탭에 YouTube 동영상이 열려 있는 동안 동영상의 특정 시간에 메모를 남길 수 있고, 메모의 시간을 클릭하면 동영상이 그 위치로 이동합니다.

메모를 남긴 동영상마다 확장 프로그램은 이 기기의 로컬 확장 프로그램 저장소(`chrome.storage.local`)에 다음을 저장합니다. 동영상의 ID와 주소(`https://www.youtube.com/watch?v=<id>`), 제목, 각 메모의 내용과 그 메모가 속한 동영상의 시간, 메모에 찍어 둔 스크린샷(동영상 화면의 그림, 너비 최대 1280픽셀), 메모를 쓰고 마지막으로 고친 시각입니다. 메모를 삭제하면 그 스크린샷도 삭제됩니다. 메모는 클라우드 동기화를 써도 **절대** 동기화되지 않으며, 어디로도 전송되지 않습니다.

이를 위해 패널에는 일시중지와 같은 youtube.com 접근 권한(위 참고)이 필요하며, 같은 "YouTube 접근 권한" 스위치로 요청합니다. 접근이 허용되면 패널이 동영상에 열려 있는 동안, 확장 프로그램에 들어 있는 작은 함수가 패널이 보이는 동안 약 1초마다 그 동영상의 현재 시간, 길이, 재생 중인지 여부, 페이지 제목을 읽습니다. 사용자가 요청하면 동영상을 메모의 시간으로 옮기고, "작성하는 동안 동영상 일시중지"를 켜 두었다면 메모를 쓰는 동안 일시중지했다가 다시 재생합니다. "스크린샷"을 누르면 그 순간 동영상에 보이는 화면을 그림으로 만들어 패널에 넘기고, 패널은 이를 새 메모와 함께 저장합니다. 페이지에서 그 밖의 것은 읽지 않으며, 읽은 내용은 사용자가 저장한 메모의 일부로만 저장됩니다.

### 클라우드 동기화(선택)

클라우드 동기화는 Tabinet을 쓰는 여러 컴퓨터 사이에서 저장된 세션과 설정을 똑같이 맞춰 줍니다. **로그인하기 전까지는 꺼져 있습니다.** 설정의 계정 항목에서 "Google로 로그인"을 눌러야 켜집니다. 로그인하지 않으면 이 섹션의 내용은 적용되지 않으며, 확장 프로그램은 네트워크 요청을 하지 않습니다.

**로그인.** Chrome이 사용자의 동의를 받은 뒤, Chrome에 로그인된 Google 계정의 Google 액세스 토큰을 확장 프로그램에 줍니다. 범위는 `openid`와 `email`뿐이며, 이메일 주소와 Google의 고유 계정 ID 외에 Google 계정의 다른 정보는 받지 않습니다. 확장 프로그램은 이 토큰을 Tabinet 동기화 서버에 한 번 보내고, 서버는 Google에 토큰을 확인한 뒤 버립니다. 확장 프로그램도 곧바로 Chrome 캐시에서 토큰을 지웁니다. 그다음 서버가 90일 동안 유효한 자체 세션 토큰을 발급하며, 확장 프로그램은 이를 로컬 확장 프로그램 저장소에 보관합니다.

**무엇을 보내고 어떻게 보호하나요.** 세션이나 설정을 보내기 전에 사용자는 동기화 암호 문구를 만듭니다. 기기 안에서 이 암호 문구로부터 키를 만들고(PBKDF2, SHA-256, 600,000회 반복, 무작위 솔트), 동기화하는 모든 데이터를 이 키로 AES-GCM(256비트) 암호화합니다. 암호 문구와 키는 어디로도 전송되지 않습니다. 암호화되어 전송되는 것은 다음과 같습니다.

- 저장된 세션: 탭의 URL과 제목, 탭 그룹, 창 배치, 그리고 저장된 세션의 삭제 기록
- 설정: 정렬 환경설정, 세션 설정, 고른 언어

자동 스냅샷은 **절대** 동기화되지 않습니다. 서버는 암호 문구나 키를 갖고 있지 않으므로 세션과 설정을 읽을 수 없으며, 암호 문구를 잊으면 저희를 포함해 누구도 복구할 수 없습니다(기기에 있는 세션에는 영향이 없습니다).

**서버에 저장되는 것.** 계정마다 이메일 주소, Google 계정 ID, 계정을 만든 시각, 그리고 기기가 암호 문구를 확인하는 데 필요한 키 설정(솔트, 반복 횟수, 암호화된 확인 값, 어느 것도 암호 문구를 드러내지 않음)을 저장합니다. 로그인마다 세션 토큰의 해시(토큰 자체는 저장하지 않음)와 만료 시각을 저장합니다. 동기화한 항목마다 암호화된 내용, 세션인지 설정인지, 무작위 식별자, 마지막으로 바뀐 시각, 삭제 여부를 저장합니다. 지운 세션은 다른 기기가 삭제를 알 수 있도록, 클라우드 데이터를 삭제할 때까지 암호화된 삭제 표시로 서버에 남습니다.

**위치.** 동기화 서버는 Vercel에서, 데이터베이스는 Neon에서 운영되며 둘 다 싱가포르 리전(아시아 태평양)에 있습니다. 두 회사는 호스팅 제공자로서 서비스를 운영하는 데에만 이 데이터를 처리합니다. 요청을 처리하는 과정에서 Vercel은 IP 주소 같은 일반적인 요청 정보를 로그에 남길 수 있습니다. 로그인할 때는 액세스 토큰을 확인하는 Google도 관여합니다.

**보관과 삭제.** 동기화된 데이터는 사용자가 지울 때까지 보관됩니다. 설정의 계정 항목에 있는 "클라우드 데이터 삭제"는 계정과 그 계정으로 서버에 저장된 모든 것을 즉시 영구히 지웁니다. 기기에 있는 세션은 남습니다. "로그아웃"은 그 기기에서 동기화를 멈추고 세션 토큰과 키를 지우지만, 다른 기기를 위해 서버의 데이터는 남겨 둡니다. 세션 토큰은 로그인하고 90일 뒤 만료되며, 그 뒤에는 다시 로그인하면 됩니다.

**사용.** 동기화된 데이터는 사용자 자신의 기기를 동기화하는 데에만 쓰입니다. 판매하지 않고, 광고, 분석, 프로파일링에 쓰지 않으며, 서비스 운영을 위한 위의 호스팅 제공자 외에는 누구와도 공유하지 않습니다.

## 데이터 보관

- 저장된 세션은 Tabinet 화면에서 사용자가 지울 때까지 보관됩니다.
- 자동 스냅샷은 순환 방식으로 보관됩니다. 보호되지 않은 스냅샷 중 가장 최근 것만 남기고(기본 20개, 개수는 Tabinet 설정에서 정할 수 있음) 오래된 것은 자동으로 지웁니다. 보호로 표시한 스냅샷은 사용자가 지울 때까지 남습니다. 브라우저를 다시 시작한 뒤 만들어지는 "이전 세션(복구됨)" 스냅샷은 자동으로 보호되며, 그 직전 것도 마찬가지입니다. 그보다 오래된 복구 스냅샷은 다시 순환 목록으로 돌아가 다른 스냅샷처럼 차례로 지워집니다. 사용자가 직접 보호로 표시한 스냅샷은 계속 보관됩니다. 스냅샷은 하나씩 또는 한꺼번에 지울 수 있습니다.
- Tabinet 화면의 "모든 세션 데이터 삭제"는 저장된 세션과 스냅샷을 모두 즉시 지웁니다. 설정과 YouTube 메모는 남습니다.
- YouTube 메모는 메모 패널에서 사용자가 지울 때까지 보관됩니다. 동영상의 마지막 메모를 지우면 그 동영상에 대해 저장된 모든 것이 지워집니다.
- 확장 프로그램을 삭제하면 Chrome이 그 기기에 저장된 데이터를 모두 지웁니다. 로그인한 적이 있다면 동기화 서버의 데이터는 "클라우드 데이터 삭제"로 지울 때까지 남습니다(이 버튼은 다시 로그인하면 쓸 수 있습니다).

## 권한

이 확장 프로그램에는 다음 권한이 필요합니다.

- **tabs**: 정렬, 세션 저장, Tabinet 화면의 열린 창 목록을 위해 탭의 URL과 제목을 읽고, 세션을 복원할 때 탭을 만듭니다.
- **tabGroups**: 현재 창의 탭 그룹을 정렬하고 정리하며, 세션을 복원할 때 탭 그룹을 다시 만듭니다.
- **storage**: 정렬 환경설정과 언어 선택을 Chrome 동기화 저장소에 저장하고, 저장된 세션, 스냅샷, 세션 설정, YouTube 메모, 그리고 클라우드 동기화를 쓰는 경우 그 세션 토큰과 키를 이 기기의 로컬 저장소에 저장합니다.
- **contextMenus**: 확장 프로그램 아이콘의 마우스 오른쪽 버튼 메뉴에 "모두 모으기", "모든 창을 세션으로 저장", "모든 YouTube 동영상 일시중지", "YouTube 메모"를 추가합니다. 웹페이지에는 메뉴 항목을 추가하지 않습니다.
- **unlimitedStorage**: 큰 세션이 Chrome의 기본 로컬 저장소 한도를 넘을 수 있게 합니다. 데이터가 저장되는 위치는 바뀌지 않으며, 어디로도 아무것도 보내지 않습니다.
- **favicon**: Tabinet 화면에서 탭 옆에 Chrome의 로컬 파비콘 캐시에 있는 사이트 아이콘을 보여 줍니다. 네트워크에서 아이콘을 가져오지 않고, 확장 프로그램이 아이콘 데이터를 저장하지도 않습니다.
- **alarms**: 사용자가 고른 간격으로 자동 스냅샷을 찍기 위한 타이머로 쓰고, 클라우드 동기화에 로그인한 동안에는 15분마다, 그리고 변경 직후에 동기화하는 데 씁니다. 자동 스냅샷을 끄고 로그인하지 않았다면 타이머가 존재하지 않습니다.
- **identity**: "Google로 로그인"을 눌렀을 때 클라우드 동기화에만 씁니다. "클라우드 동기화"에 설명한 대로 `openid`와 `email` 범위의 Google 액세스 토큰을 Chrome에 요청합니다. 로그인하지 않으면 쓰지 않습니다.
- **scripting**: YouTube에서만 씁니다. "YouTube 동영상 일시중지"에 설명한 대로 사용자가 요청할 때 동영상을 일시중지하고, "YouTube 메모"에 설명한 대로 동영상의 시간과 제목을 읽고 메모의 시간으로 옮기며, 요청할 때 스크린샷을 찍습니다. 아래에서 허용한 사이트에서만 동작합니다.
- **sidePanel**: 마우스 오른쪽 버튼 메뉴, 단축키, Tabinet 화면에서 열 때 Chrome 사이드 패널에 YouTube 메모를 보여 줍니다. 아이콘을 클릭해서는 열리지 않습니다.
- **youtube.com 접근 권한** (선택, `https://*.youtube.com/*`): 설정이나 메모 패널에서 "YouTube 접근 권한"을 켤 때만 요청하며, 설정에서 해제할 수 있습니다. 동영상 일시중지와, YouTube 메모를 위해 동영상의 시간과 제목을 읽고 위치를 옮기고 요청할 때 스크린샷을 찍는 데에만 쓰며, YouTube 페이지에서 그 밖의 것은 읽지 않습니다.

이 확장 프로그램은 설치할 때 호스트 권한을 요청하지 않고 콘텐츠 스크립트를 선언하지 않습니다. youtube.com 접근 권한은 선택 사항이며, 허용 여부는 사용자가 정합니다. Chrome 123 이상이 필요합니다.

## 데이터 사용

- 탭의 URL과 제목은 정렬하는 동안 읽히며, 정렬 과정에서 저장되지 **않습니다**.
- 세션을 저장할 때나 자동 스냅샷이 켜져 있는 동안, 위에 나열한 데이터는 기기의 로컬 확장 프로그램 저장소에 저장됩니다. 클라우드 동기화에 로그인한 경우에만, 그것도 저장된 세션과 설정만 종단 간 암호화되어 전송되며, 자동 스냅샷은 전송되지 않습니다.
- 정렬 환경설정은 Chrome의 기본 저장소 API로 저장되며, 클라우드 동기화를 쓰면 암호화되어 동기화 서버에도 저장됩니다. 제3자와 공유되지 않습니다.
- 어떤 데이터도 판매, 공유되지 않으며, 탭 정렬, 요청한 YouTube 동영상 일시중지, YouTube 동영상 메모 보관, 세션의 저장, 복원, 검색, 가져오기, 내보내기, 그리고 로그인한 경우 동기화 외의 목적으로 쓰이지 않습니다.

## 제3자 서비스

Tabinet은 제3자 분석, 추적, 데이터 수집 서비스를 **쓰지 않습니다**. 클라우드 동기화는 로그인한 경우에만 Google 로그인과 호스팅 제공자 Vercel, Neon을 씁니다("클라우드 동기화" 참고).
